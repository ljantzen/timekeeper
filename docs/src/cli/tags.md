# Tags

```text
tmkpr tag list
```

Lists all tags in use across entries, with entry counts. Accepts `--format` like any other list command (see [Output Formats](./output-formats.md)).

Tags are attached to entries at creation (`start --tags`, `log --tags`, `event add --tags`) or updated afterward with `edit --tags` / `--add-tag` / `--remove-tag` (see [Entries](./entries.md)). Filter entries or reports by tag with `--tag TAG` on `list`, `report`, and `event list`.
